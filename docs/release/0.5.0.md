# TrustBoundary 0.5.0 Release Candidate

## Public 0.5 surfaces

CLI:

```text
trustboundary invariant-evaluate INPUT.json
```

Local API:

```text
POST /api/v1/analysis/invariants/evaluate
```

Invariant evaluation compares modeled/observed transitions with explicit trust expectations. Automated outcomes are limited to `OBSERVED`, `HYPOTHESIS` and `UNKNOWN`; they never establish exploitability or create a validated finding.

Use the coordinated Sentinel Forge 0.5 release train from sibling checkouts. `doctor` requires SRIC 0.5 for this candidate.
