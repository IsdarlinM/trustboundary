# TrustBoundary Mapper 0.5.13

Date: 2026-08-10

## Guided Web Security Console

TrustBoundary Mapper keeps its evidence-linked trust graph quick view and moves complete operations to the shared SRIC Core 0.5.13 guided Security Console.

- Dashboard navigation is `Dashboard / Security Console / API`.
- `Advanced Console` is removed from user-facing navigation.
- The Security Console renders real TrustBoundary capabilities as structured operation cards with checkboxes, selectors, numeric/path controls and repeated-value controls; users do not enter CLI commands or free-form argv.
- The historical `/console` route is only a compatibility alias to `/workbench`.
- Trust assumptions and inconsistencies remain evidence-linked inferences/hypotheses and are not promoted to exploitation or validation without evidence.
